# Etleap

> Etleap is a managed ETL and data-integration platform that streamlines data ingestion, transformation, and observability so data teams can build cloud data warehouses and lakes with minimal engineering effort. It continuously ingests operational data from 50+ databases, SaaS applications, event streams, and files; shapes it with visual data wrangling and dbt Core; and loads it into Amazon Redshift, Snowflake, Databricks, Amazon S3, and Apache Iceberg. Etleap exposes a REST API v2 (HTTP Basic auth) and ships an official Terraform provider.

## APIs

- [Etleap API v2](https://docs.etleap.com/docs/api-v2): Create and manage connections, pipelines, models, dbt schedules, teams, and users. Base URL https://api.etleap.com/api/v2, HTTP Basic authentication.
